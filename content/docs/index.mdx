Railzway is an open-source billing engine for metering usage, applying commercial
terms, and producing reproducible financial records.

<Callout title="Contract-first API">
  The public API is defined in versioned Protocol Buffer packages and exposed
  through both gRPC and REST/JSON transcoding.
</Callout>

## Billing data flow

```text
usage event -> meter -> product -> effective rate -> contract
            -> rated charge -> credits -> invoice -> payment
```

Railzway keeps billing computation separate from payment collection. Finalizing
an invoice records what is owed; collecting it is an explicit operation.
