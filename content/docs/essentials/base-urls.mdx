---
title: Base URLs
description: Address an organization through its default or custom API hostname.
---

Every Railzway Cloud organization receives an active default hostname when it
is created. The hostname is derived from its DNS-safe organization name:

```text
https://{org_name}.railzway.app
```

For example, an organization named `acme` uses this REST base URL:

```text
https://acme.railzway.app
```

API paths already contain the version prefix:

```text
https://acme.railzway.app/v1/customers
```

`railzway.app` is the managed Railzway Cloud domain. A self-hosted installation
can configure another DNS suffix through `domains.default_root`; the development
default is `fare.local`.

<Callout title="The hostname is part of tenant isolation">
  Fare resolves the organization from the HTTP `Host` header. An API key is
  rejected if its organization does not match the organization assigned to the
  hostname.
</Callout>

You can later expose the same organization through a [custom domain](./custom-domains).
The API paths and API key do not change.
